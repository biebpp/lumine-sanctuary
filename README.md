# Traveler's Sanctuary

A warm, golden-brown desktop theme inspired by the Traveler's journey.

## Color palette

| Color | Hex | Intended use |
|---|---|---|
| Starless Bronze | `#29231C` | Main dark background
| Ancient Umber | `#393027` | Secondary surfaces
| Traveler's Gold | `#D9B96E` | Active borders and highlights
| Celestial Ivory | `#F4F0E8` | Readable text and emphasis
| Earthbound Umber | `#755640` | Earthy accent
| Moonlit Blue | `#9EBED5` | Cool complementary accent
| Muted Bronze | `#5B4A36` | Inactive borders and subtle details

## Components

- `hypr/`: Hyprland configuration
- `kitty/`: Kitty terminal configuration and theme
- `noctalia/`: Noctalia custom palette

## Safety

Review machine-specific settings before reusing this configuration.
Never commit credentials, access tokens, or private keys.
